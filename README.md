# LAB // VISUAL 50

Galería interactiva con **50 experimentos de CSS puro, Canvas y JavaScript** lista para publicar en **GitHub Pages**.

## Contenido del ZIP
- `index.html`: Estructura completa con los 50 experimentos divididos en 5 categorías.
- `style.css`: Estilos modernos, glassmorphism, animaciones 3D, paisajes CSS y efectos de cursor.
- `script.js`: Interactividad, partículas, física de gravedad, fractales, esfera 3D y visualizador de audio.

## Cómo subirlo a GitHub Pages
1. Descomprime este archivo `.zip`.
2. Sube `index.html`, `style.css` y `script.js` a la raíz de tu repositorio en GitHub.
3. En tu repositorio, entra en **Settings > Pages**, selecciona la rama `main` y guarda.
